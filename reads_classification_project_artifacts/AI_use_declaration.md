# AI Use Declaration

During this project, generative Artificial Intelligence tool was used for the following purposes:

(1) Debugging Python and Bash scripts.
(2) Providing principle explanation and draft of scripts in velocyto and scVelo analysis process.
(3) Providing suggestions for code improvements in structure and reproducibility.

All the final scripts, analysis, validation, interpretation, and decision-making processes were reviewed by the project author. AI-generated suggestions were also checked and modified before release of the final artifact.
