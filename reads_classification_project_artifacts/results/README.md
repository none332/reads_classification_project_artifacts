# Results Directory

## Overview
This directory stores the outputs generated in the workflow, including intermediate files, read classification results, loom files, and downstream scVelo/pyGenomeTracks analysis outputs. Some files represent temporary processing results, while others correspond to the final outputs used for downstream interpretation.

## Directory Structure
```text
results/
├── README.md
├── short_read/
│   └── velocyto/
├── long_read/ 
├── pygenometracks/
└── scvelo/
```

The scripts will construct built-in function to automatically create output directories, so those generated folders are not fully listed in the structure above.

## Short-read Results
The short_read/ directory may contain:
- trimmed fastq files
- aligned bam files
- sorted and filtered bam files
- preliminary read classification results
- final read classification results
- summary tables of spliced, unspliced, and ambiguous reads

In the short_read/ directory, this repository provides example outputs of single-end sample SRR5674607 in "example_final_results_SRR5674607" folder. It includes 3 classified bam files and their indexes, and a summary quantitative tsv file.

# The short_read/velocyto/ directory may contain:
- bam files with artificial CB and UB tags added to each read for compatiblity with velocyto
- single sample output directories containing loom files generated by velocyto
- merged summary table of spliced, unspliced, and ambiguous read counts across samples

In the short_read/velocyto/ directory, this repository provides example outputs as "example_loom_mm39_summary.tsv". It displays the summary of read counts of three categories of all the samples.

## The long_read/ directory may contain:
- aligned, sorted and filtered bam files
- preliminary read classification results
- final read classification results
- summary tables of spliced, unspliced, and ambiguous reads

In the long_read/ directory, this repository provides example outputs of a summary quantitative "example_read_summary.tsv" file, which demonstrates the counts of input reads and the final classified reads.

## The scvelo/ directory may contain:
- processed count matrices of this method
- reformatted matrices used as scVelo input
- cell-level annotation files
- velocyto merged count matrices
- visualisation files
- comparison plots between the proposed method, velocyto, and an extra ambiguous-added data

In the scvelo/ directory, this repository provides example outputs of all the figures generated from the default input data. It also includes a log file and an "example_scvelo_compare_summary.csv" file with quantitative results and comparison.

## The pygenometracks/ directory may contain:
- coverage tracks converted from BAM files
- BED12 files representing individual read structures in the selected genomic region
- pyGenomeTracks configuration files
- final visualization figures

In the pygenometracks/ directory, this repository provides example outputs of two visualized figures "example_mouse_mm39_SRR5674607_pyGenomeTracks.png" and "example_human_hg38_t_generation_pyGenomeTracks". They display the reads distribution and comparison between the three bam categories of chr5:142889418-142891961 (Actb) in mouse genome and chr12:6536257-6538490 (Gapdh) in human genome.

## Notes
Not all result files are included in this repository due to file size limitations. The provided files under results directories are example outputs intended to illustrate the expected results of each workflow.
