### A Mature/Precursor/Ambiguous Read Classification workflow and validation through pyGenomeTracks and scVelo Analysis

### Overview
This artifact repository contains the scripts, documentation, analysis workflow and example results for my Final Year Project (FYP) for a read classification method. The project investigates whether a stricter classification strategy of reads into mature (spliced), precursor (unspliced), and ambiguous can work reliably. To visualize the classified reads, this project plots genome track graphs through pyGenomeTracks tool. This project also compares the new method with a standard velocyto-based pipeline through downstream scVelo analysis.

### Research Aim
The main aim of this project is to develop a tool for precisely classifying and quantifying mature, precursor, and ambiguous reads.

### Input data
Raw data are not fully included in this repository due to file size limitation.
A description of the required input files can be found in data/README.md.

Required inputs include:
(1) Fastq file of short_read sequencing or long_read sequencing (This repository provides a short-read sequencing sample SRR5674607.fastq.gz as an example input sample under data/short_read/sequences directory).
(2) Gene annotation file in gtf format
(3) Reference genome in fasta format
(4) Exon and intron annotation .bed files
(5) cell embedding file (This repository provides 369 embedding data for GSE99933 dataset with 15 unavailable samples. It can be found in reads_classification_project_artifacts/data/scvelo)
cell colour/group annotation file (This repository provides 369 cell group data for GSE99933 dataset with 15 unavailable samples. It can be found in reads_classification_project_artifacts/data/scvelo)

### Workflow
This part provides the main workflow of this project. When reproducing, you can run the scripts in the following process:
## Short_read data processing
In the step 1-6, the scripts locate in reads_classification_project_artifacts/scripts/methods/short_read

(1) Prepare cleaned exon and intron BED files:

  ```bash
  bash 1_preparation.sh
  ```
Input:
- exon and intron bed files

Output:
- cleaned exon and intron bed files

(2) Trim the raw single-end fastq data:

  ```bash
  bash 2_trim.sh
  ```

Input:
- single-end fastq files

Output:
- trimmed fastq files

(3) Alignment:

  ```bash
  bash 3_align.sh
  ```

Input:
- trimmed fastq files
- genome annotation in gtf format
- pre-built STAR genome index files

Output:
- aligned bam files

(4) Sort the BAM and filter reads:

  ```bash
  bash 4_sort_filter.sh
  ```

Input:
- aligned bam files

Output:
- sorted, mapQ30 filtered bam files

(5) Divide reads into different classes preliminarily:

  ```bash
  bash 5_divide.sh
  ```

Input:
- sorted, mapQ30 filtered bam files

Output:
- mRNA reads bam files
- three groups of classified (spliced, pre-mRNA isoform-ambiguous) bam files

(6) Final classification:

  ```bash
  bash 6_method_final.sh
  ```
Input:
- three groups bam files generated in step 5

Output:
- final classified bam files (spliced, unspliced, ambiguous)


In the step 7, the scripts locate in reads_classification_project_artifacts/scripts/velocyto

(7) Run velocyto on the same samples, the submit_workflow.sh can directly submit the main workflow script:

  ```bash
  bash submit_workflow.sh
  ```

Input:
- sorted, mapQ30 filtered bam files generated in step 4
- repeat mask GTF
- GTF annotation

Output:
- velocyto summary loom file for each sample
- summary counts of three categories of reads

In the step 8-12, the scripts locate in reads_classification_project_artifacts/scripts/scvelo

(8) Run featureCounts on three BAM files generated by our method:

  ```bash
  bash 1_genecounts.sh
  ```

Input:
- final classified bam files generated in step 6

Output:
- gene-count tables for each sample

(9) Merges all SRR gene-count tables into three matrices:

  ```python
  python 2_merge_matrix.py
  ```

Input:
- gene-count tables for each sample

Output:
- three merged gene-count tables for all the sample

(10) Transfer the three matrices into gene-name matrices, the 3_run_matrix_process.sh can directly submit the main process script:

  ```bash
  bash 3_run_matrix_process.sh
  ```

Input:
- three merged gene-count tables for all the sample

Output:
- three cleaned merged gene-count tables

(11) Extract and merge velocyto matrices generated in step 7:

  ```python
  python 4_loom_export.py
  ```

Input:
- velocyto summary loom file for each sample generated in step 7

Output:
- three merged velocyto gene-count tables

(12) Run scVelo analysis to compare the classification, provide visualized graphs in the outputs:

  ```python
  python 5_scvelo.py
  ```

Input:
- the three tables generated in step 10 and the three tables generated in step 11

Output:
- final figures for comparison between the two methods
